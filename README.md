Adobe India Hackathon 2025 — Connecting the Dots Challenge
Rethink Reading. Rediscover Knowledge.
What if a PDF wasn’t just static text, but an intelligent companion—one that connects ideas, narrates context, and guides your exploration across an entire library?

That’s the vision behind Connecting the Dots—and this project brings that future to life.

Challenge Overview
Adobe’s "Connecting the Dots" challenge is about transforming the traditional reading experience into something dynamic and insightful. The focus is on turning PDFs into intelligent, interactive documents that can understand structure, highlight key ideas, and support exploratory research.

The Two-Phase Journey
Round 1 — Intelligence Layer
Develop a robust pipeline to extract structured outlines from raw PDFs at high speed and accuracy. Build a lightweight, local intelligence layer capable of identifying sections and linking related concepts.

Round 2 — Interactive Web App
Leverage Adobe’s PDF Embed API to build a futuristic, user-friendly web application. Use your Round 1 engine to power interactive reading experiences that feel intuitive and assistive.

Why It Matters
In an era of overwhelming information, tools that provide context are more valuable than those that merely present content. This challenge is about redefining how we read, learn, and connect through documents.

Whether you're working on machine learning, UI/UX, or information retrieval—this platform is a place to innovate.

Solutions
Challenge 1a — PDF Processing Solution
Structured PDF parsing using containerized services with intelligent segmentation and metadata extraction.

Challenge 1b — Multi-Collection Content Analysis
Persona-driven analysis engine designed to uncover thematic connections across large collections of PDFs.
